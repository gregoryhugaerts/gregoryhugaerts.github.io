CTF and Lab Platforms

Description

Theoretical knowledge of security concepts must be reinforced through hands-on practice. CTF competitions and lab platforms provide structured, legal environments for this. They range from fully guided beginner rooms to competitive challenges requiring advanced exploitation skills. Building a home lab extends this further by allowing experimentation with real tools and configurations.

CTF Format Types

Jeopardy Style

The most common beginner format. Challenges are divided into categories, each worth points. Solving a challenge yields a flag — a string in a defined format (e.g., FLAG{...}) submitted for points. Common categories:

  • Web — SQL injection, XSS, SSRF, authentication bypass
  • Forensics — File analysis, memory dumps, PCAP analysis
  • Crypto — Breaking or exploiting weak cryptographic implementations
  • Reverse Engineering — Analysing binaries to find hidden functionality
  • Pwn / Binary Exploitation — Buffer overflows, ROP chains
  • OSINT — Open-source intelligence gathering
  • Misc — Steganography, encoding, logic puzzles

Attack / Defence

Teams simultaneously attack opponent infrastructure and defend their own. Requires both offensive and defensive skills. More common at advanced/professional level events.

King of the Hill

Players compete to compromise a shared machine and maintain access longest. Used on platforms like TryHackMe.

Guided Learning Platforms

These platforms provide structured learning paths, making them ideal for beginners.

TryHackMe

  • URL: https://tryhackme.com
  • Format: Browser-based, guided rooms with questions and hints
  • Access: Free tier + subscription
  • Best for: Absolute beginners through to intermediate
  • Strength: No local setup required; in-browser attack box available
  • Notable paths: Pre-Security, SOC Level 1, Jr Penetration Tester, Cyber Defence

HackTheBox (HTB)

  • URL: https://hackthebox.com
  • Format: Unguided machines (beginner machines available), labs, and Academy
  • Access: Free tier + subscription (VIP for retired machines with write-ups)
  • Best for: Intermediate to advanced; HTB Academy is good for beginners
  • Strength: Realistic machines, large community, respected in industry
  • Notable: Retired machines have community write-ups available legally

PortSwigger Web Security Academy

  • URL: https://portswigger.net/web-security
  • Format: Guided labs covering every major web vulnerability
  • Access: Completely free
  • Best for: Web application security focus
  • Strength: Directly tied to ; widely considered the best free web security resource
  • Notable paths: SQL Injection, XSS, SSRF, OAuth, JWT attacks

PicoCTF

  • URL: https://picoctf.org
  • Format: Jeopardy-style, beginner-friendly
  • Access: Free
  • Best for: Absolute beginners; originally designed for high school students
  • Strength: Low barrier to entry; covers core CTF categories without overwhelming complexity

VulnHub

  • URL: https://vulnhub.com
  • Format: Downloadable vulnerable VMs to run locally
  • Access: Free
  • Best for: Intermediate; requires a local hypervisor setup
  • Strength: Offline practice; huge archive of machines with varying difficulty

OWASP WebGoat / VWA

  • Locally hosted intentionally vulnerable web applications
  • (DVWA) — classic, covers OWASP Top 10
  • WebGoat — OWASP maintained; more guided with explanations
  • Best for: Web vulnerability practice in a fully offline environment

Home Lab Setup

A home lab allows practice with real tools in a controlled environment without relying on external platforms.

Virtualisation Software

  • VirtualBox — Free, cross-platform hypervisor (recommended for beginners)
  • VMware Workstation Pro — More performant; now free for personal use
  • Proxmox VE — Bare-metal hypervisor for dedicated lab machines

Core Lab VMs

A minimal useful lab setup:

VM Purpose
Kali Linux Primary attack machine; pre-loaded with tools
ParrotOS Alternative attack machine; lighter than Kali
Windows Server AD lab target; practice domain attacks
Windows 10/11 Domain-joined workstation target
Metasploitable2 Intentionally vulnerable Linux for exploitation
Ubuntu Server General purpose target; web server practice

Network Isolation

All lab VMs should run on a host-only or internal network adapter in the hypervisor. This prevents malicious or vulnerable VMs from reaching the internet or the host network.

Recommended Starting Configuration

  1. Install VirtualBox
  2. Create a host-only network (192.168.56.0/24 by default in VirtualBox)
  3. Deploy Kali Linux as attack machine
  4. Deploy one target (Metasploitable2 or a VulnHub machine)
  5. Confirm network isolation before powering on targets
  6. Snapshot VMs before any exploitation to allow easy revert

Suggested Learning Path

A structured progression for a beginner:

  1. Networking & Linux basics — TryHackMe Pre-Security path
  2. Web fundamentals — PortSwigger Academy (Apprentice labs)
  3. First CTF flags — PicoCTF archived challenges
  4. Guided machines — TryHackMe Easy rooms (e.g., Blue, Basic Pentesting)
  5. Unguided machines — HTB Starting Point, then Easy-rated retired boxes
  6. Web depth — PortSwigger Academy (Practitioner labs)
  7. Active Directory — TryHackMe AD paths, then HTB Windows machines
  8. Home lab — Build AD environment; practice BloodHound, Mimikatz in isolation
  9. Live competition — Enter a beginner CTF event via CTFtime.org
