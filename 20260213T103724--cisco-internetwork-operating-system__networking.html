Cisco Internetwork Operating System

Overview

What is Cisco iOS?

  1. Cisco Internetwork Operating System (iOS) is the proprietary software that runs on most Cisco networking devices, including routers, switches, and access points.
  2. It provides the core functionality for network communication, such as routing, switching, and security.

Key Components

  1. Cisco IOS Shell: The command-line interface (CLI) used to interact with the device and configure its settings.
  2. Routing Information Protocol (RIP), Open Shortest Path First (OSPF), Enhanced Interior Gateway Routing Protocol (EIGRP), Border Gateway Protocol (BGP): Routing protocols for efficient data transfer within and between networks.
  3. Access Control Lists (ACLs): Security mechanisms to filter network traffic based on source/destination IP addresses, ports, and other criteria.
  4. Quality of Service (QoS): Mechanisms to prioritize network traffic, ensuring critical applications (like voice and video) receive sufficient bandwidth.
  5. Virtual Local Area Networks (VLANs): Segmenting a physical network into multiple virtual networks for improved security and manageability.
  6. Spanning Tree Protocol (STP): Prevents network loops in Ethernet networks, ensuring data delivery.

Usage

Network Configuration

  1. Configure routing protocols to establish inter-network connectivity.
  2. Define VLANs to segment network traffic and improve security.
  3. Implement ACLs to control network access and filter traffic.
  4. Configure QoS to prioritize critical applications.
  5. Implement security features like firewalls and intrusion detection.

Network Troubleshooting

  1. Use CLI commands to diagnose network problems, such as connectivity issues, routing loops, and performance bottlenecks.
  2. Analyze system logs to identify and resolve network errors.
  3. Utilize debugging tools to pinpoint the root cause of network problems.

Network Monitoring

  1. Monitor network performance metrics, such as bandwidth utilization, latency, and packet loss.
  2. Collect and analyze network traffic data for performance tuning and capacity planning.

Commands

Mac Address

  1. Showing MAC Addresses
    • show mac address-table: Displays all MAC addresses learned by the switch.
    • show mac address-table <interface-name>: Displays MAC addresses learned on a specific interface.
    • show mac address-table address <mac-address>: Displays the port associated with a specific MAC address.
    • show mac address-table dynamic: Displays only dynamically learned MAC addresses.
    • show mac address-table vlan <vlan-id>: Displays MAC addresses associated with a specific VLAN.
  2. Clearing MAC Addresses
    • clear mac address-table: Clears all MAC addresses from the table.
    • clear mac address-table dynamic: Clears only dynamic MAC addresses.
    • clear mac address-table static: Clears only static MAC addresses.
    • clear mac address-table address <mac-address>: Clears a specific MAC address from the table.
    • clear mac address-table address <mac-address> interface <interface-name>: Clears a specific MAC address from a specific interface.

Misc Commands

  • no <command>: Undo a previously entered command.
  • do <command>: Execute privileged EXEC commands while in another mode.

Password Configuration

  • enable password <password>: Set a basic password for privileged EXEC mode.
  • enable secret <password>: Set an encrypted password for privileged EXEC mode.
  • service password-encryption: Encrypt all plain-text passwords in the current configuration.

Saving and Viewing Configuration

  • show running-config: Display the current active configuration.
  • show startup-config: Display the saved configuration used at startup.
  • write: write memory
  • copy running-config startup-config: Save the running configuration to the startup configuration.

Switch Modes

  • enable: Switch to privileged EXEC mode from user EXEC mode.
  • configure terminal (or conf t): Enter global configuration mode.
